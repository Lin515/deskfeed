# assets

品牌资源与应用图标资源。

| 文件 | 作用 |
| --- | --- |
| `deskfeed-icon.svg` | 应用图标的唯一矢量源（256 × 256 画布），透明背景，可无损缩放 |
| `deskfeed.ico` | 由 SVG 逐尺寸导出的 Windows 图标：16/20/24/32/40/48/64/128 为 BMP 条目，256 为 PNG 条目 |
| `deskfeed.rc` | 资源脚本：资源 ID 1 的 `RT_GROUP_ICON`，挂给 `deskfeed.exe` 与 `deskfeed-inject.exe`；主进程的通知区域（托盘）图标也按小图标尺寸从这里加载 |

## 图形与配色

- 主体为斜向、弧边的白色悬浮窗，内部三行分别由浅色标签与青蓝读数组成；
- 底部蓝色任务栏贴合窗体弧线，白色胶囊表示任务栏嵌入式读数组件；
- 背景透明，不包含外围光带、信号球或星点。

图标使用独立的亮色品牌配色，不随悬浮窗深浅主题联动。图形由矢量色块与渐变构成，
不依赖字体、外部图片或模糊滤镜。诊断工具（`deskfeed-check`、`deskfeed-probe`）刻意不挂图标，
避免与产品本体混淆。

## 更新流程

修改 `deskfeed-icon.svg` 后先验收视觉效果，确认后再导出 `deskfeed.ico` 并重新构建。
导出时按上面列出的尺寸逐个栅格化 SVG（小尺寸不要用大图缩放，否则 16/20/24 px 会发糊），
保留透明通道，小尺寸存 BMP 条目、256 存 PNG 条目；这一步不在构建流程里，仓库只需要提交
矢量源与导出好的 `.ico`。`CMakeLists.txt` 已把 `.ico` 设为 `deskfeed.rc` 对应 `.res` 的隐式依赖，
换图标会触发资源重编。
