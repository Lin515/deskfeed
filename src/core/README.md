# src/core

协议与状态机的纯逻辑层。不含 Windows 调用（`utf8.cpp` 只用系统提供的 UTF-8/UTF-16 转换），
不联网、不读写磁盘、不开窗口，因此可以整体搬进离线用例。

| 文件 | 作用 |
| --- | --- |
| `json.h` / `json.cpp` | 严格的只读 JSON 解析器：对象、数组、字符串（含 `\uXXXX` 与代理对）、数字、布尔、null；拒绝重复成员、尾随内容、非法 UTF-8 与过深嵌套；提供“按数值精确判断是不是整数”的换算（不经过 double）。 |
| `snapshot.h` / `snapshot.cpp` | 协议 v1 的模型与严格校验。容量常量（正文 1 MiB、条目 64、各字段字节上限、深度 32、安全整数上界）只有这一处定义；校验失败给出分类与一行原因。 |
| `health.h` / `health.cpp` | 健康、缓存、到期状态机与 `View`（`waiting` / `content` / `error` + 是否整体失效 + 原因）。完整替换、失败即全红、合法清空、独立到期、恢复各项状态都在这里。 |
| `schedule.h` / `schedule.cpp` | 调度默认值与上下限、夹取，以及“成功等轮询、失败等重试”的排程。 |
| `utf8.h` / `utf8.cpp` | UTF-8 严格校验与逐码位解码、宽窄字符串互转、Unicode White_Space 空白判据、单行判据。 |
