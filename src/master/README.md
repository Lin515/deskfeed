# src/master

| 文件 | 作用 |
| --- | --- |
| `main.cpp` | `wWinMain`：取命令行，交给 `master_main`。 |
| `master.h` / `master.cpp` | 主进程全部逻辑：实例命名空间与安全描述符、单实例仲裁与命令转发、控制窗口处理器、配置事务（校验 → 准备绑定 → 落盘 → 提交运行时）、取数作业调度与墙钟截止、到期定时器、消息循环、`--inspect` 的 JSON、收尾顺序。 |

时钟域：健康/到期用墙钟 Unix 毫秒，调度与超时用单调时钟。

单实例仲裁在 `master_main` 里先于控制窗口与日志完成；日志在接收端就绪之后才截断。
