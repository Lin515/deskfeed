# src/net

| 文件 | 作用 |
| --- | --- |
| `url.h` / `url.cpp` | URL 解析（只接受 http/https、要求主机名、只丢片段保留查询串、拒绝空白与控制字符）、RFC 3986 相对解析与点段合并、日志用脱敏（去掉 userinfo/查询串/片段）。 |
| `http_client.h` / `http_client.cpp` | 唯一的取数入口 `http_get`：只发 GET、只接纳 200、手动跟最多 5 跳重定向、禁 HTTPS→HTTP 降级、正文上限 1 MiB、不使用系统代理、**异步 WinHTTP 驱动的整次墙钟预算与真取消**（到点或取消即关闭在途请求句柄；句柄各自持有一份上下文强引用，正文缓冲区由上下文持有）。 |

检查器与主进程都走这一份实现，所以“会不会接纳某份响应”不存在第二种解释。
整次墙钟取消的实现与生命周期规则见本文件顶部的 `http_client.cpp` 说明与
[docs/http.md](../../docs/http.md) 的“墙钟预算与线程模型”。
